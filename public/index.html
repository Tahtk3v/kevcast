Open KevCast Web Studio

Prefer an app? Install KevCast Studio. It finds this server automatically.

Turn a screen into a player

With a web browser (smart TV, PC, tablet): open this page in full screen:

  1. The screen shows a 6-character code.
  2. In the Web Studio go to Displays → Add display and enter it.
  3. Press F11 on the screen for full screen.

For PCs, mini-PCs and Raspberry Pi, the KevCast Player app is recommended: it starts automatically, keeps playing offline and can only be closed with Alt+Q.
